# Артефакты моделей

В эту папку можно положить опциональные артефакты, полученные из основных
ноутбуков ВКР. Если артефактов нет, демо запускается на rule-based fallback.

## Ожидаемые файлы

| Имя файла | Назначение | Формат |
|-----------|------------|--------|
| `intent_model.joblib` | Обученный классификатор интентов (например, `Pipeline(vectorizer, classifier)` или sklearn-совместимый объект с `predict`/`predict_proba`). | `joblib` |
| `intent_label_encoder.joblib` | `LabelEncoder` со списком 14 классов из ВКР. | `joblib` |
| `topic_centroids.npy` | Матрица центроидов тематических кластеров, shape `(n_clusters, dim)`. Эмбеддинги совместимы с `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (или совместимым). | `numpy.save` |
| `topic_metadata.parquet` | Метаданные кластеров с колонками `cluster_id`, `name`, `description`, `top_words` (list[str] или строка через `,` / `;`). | `pyarrow` parquet |

## Как подключить

1. Скопируйте нужные файлы в `dialogsum_intent_webapp/models/`.
2. Перезапустите приложение (`python app.py`). При загрузке выведутся
   сообщения вида `Загружен intent_model.joblib`.

## Ограничения fallback

- `intent`: словарь ключевых слов → один из 14 классов; не отличает близкие
  по словам, но разные по смыслу реплики.
- `topic`: 10 предопределённых тем из ВКР, выбирается по совпадению ключевых
  слов; не использует эмбеддинги.
- `summary`: всегда возвращает `None` со статусом
  «Суммаризация не подключена в демо-версии».

Если артефакты подключены, fallback автоматически отключается для
соответствующего модуля.
