# Семантический анализ русскоязычных диалогов для распознавания намерений

Репозиторий с кодом и материалами магистерской ВКР:

> **«Семантический анализ русскоязычных диалогов для задачи распознавания намерений с улучшением на базе предобученных моделей»**
>
> Шкаровский Владислав Семёнович, НИУ ИТМО, магистратура, образовательная программа «Аналитика данных».

## Краткое резюме

ВКР посвящена построению и эмпирическому исследованию конвейера семантического анализа русскоязычных диалогов. Конвейер объединяет два уровня:

1. **Тематическое моделирование** корпуса диалогов с интерпретируемым представлением — эмбеддинги предложений, снижение размерности UMAP, кластеризация HDBSCAN и автоматическая интерпретация кластеров с помощью LLM.
2. **Распознавание намерений** на уровне отдельных реплик и на уровне диалога в целом с использованием классических моделей, sentence embeddings и предобученных языковых моделей (RuBERT-tiny2 и др.). Тематические кластеры используются как контекстный признак.

Корпус — `DialogSum-RU` (`d0rj/dialogsum-ru`), 14 460 диалогов. Дополнительно вручную и через слабую разметку построены датасеты для интентов реплик (4 722 реплики) и интентов диалогов (1 246 диалогов).

## Цель и задачи

**Цель** — разработать и эмпирически исследовать конвейер семантического анализа русскоязычных диалогов, обеспечивающий интерпретируемое тематическое представление корпуса и распознавание намерений на уровне отдельных реплик с использованием тематических кластеров как контекстного признака и предобученных языковых моделей.

**Основные задачи:**

- провести обзор существующих подходов к распознаванию намерений и тематическому моделированию русскоязычных диалогов;
- описать датасет `DialogSum-RU` и провести EDA;
- построить тематическую модель корпуса (LDA, NMF, embeddings+UMAP+HDBSCAN) и сравнить подходы;
- сформулировать схему намерений из 14 классов речевых актов;
- получить слабо размеченные и вручную проверенные наборы данных для интент-классификации;
- обучить и сравнить классические, embedding-based и предобученные модели для распознавания намерений на уровне реплик и диалога;
- проанализировать вклад тематического контекста в качество классификации;
- зафиксировать ограничения и направления развития исследования.

## Данные

Используется датасет [`d0rj/dialogsum-ru`](https://huggingface.co/datasets/d0rj/dialogsum-ru) — машинно-переведённая русскоязычная версия DialogSum.

| Поле | Описание |
| --- | --- |
| `id` | Идентификатор диалога |
| `dialogue` | Текст диалога (реплики с маркерами спикеров `#Person1#`, `#Person2#`) |
| `summary` | Краткое резюме диалога |
| `topic` | Краткая тема (свободная форма) |

Сплиты: `train`, `validation`, `test`. Итого 14 460 диалогов. Дополнительные риски — машинный перевод, дисбаланс тем, потенциальные дубликаты — обсуждаются в главе 3 и 8 ВКР.

## Методологический пайплайн

```
DialogSum-RU
   │
   ├──► EDA (длины, спикеры, темы, дубликаты)
   │
   ├──► Тематическое моделирование
   │       ├── LDA / NMF (baselines)
   │       └── Sentence embeddings + UMAP + HDBSCAN + LLM-интерпретация
   │
   └──► Распознавание намерений
           ├── Схема из 14 классов речевых актов
           ├── Слабая разметка через эвристические правила
           ├── Ручная валидация подвыборок
           ├── Уровень реплики: TF-IDF / embeddings / + тематический кластер
           └── Уровень диалога: RuBERT-tiny2 fine-tuning с весами классов
```

## Ключевые результаты

### Тематическое моделирование

| Метрика | Значение |
| --- | --- |
| Подход | Sentence embeddings + UMAP + HDBSCAN + LLM-интерпретация |
| Число кластеров | 208 |
| Silhouette score | **0.7623** |
| Доля шумовых записей | 17.1% |
| Объём корпуса | 14 460 диалогов |

Подход на эмбеддингах превзошёл LDA и NMF по разделимости и интерпретируемости кластеров.

### Распознавание намерений — уровень реплики (4 722 реплики, 14 классов)

| Модель / признаки | macro-F1 |
| --- | --- |
| **TF-IDF + LogisticRegression** | **0.66** |
| TF-IDF + LogisticRegression + тематический кластер | 0.61 |
| Sentence embeddings + LogisticRegression | 0.38 |

### Распознавание намерений — уровень диалога (1 246 диалогов, clean-сценарий)

| Модель | macro-F1 |
| --- | --- |
| **RuBERT-tiny2, fine-tuning с весами классов** | **0.41** |

Тематический кластер как дополнительный признак **не улучшил** распознавание речевых актов, но оказался полезным промежуточным представлением для отбора тематически чистых обучающих выборок.

## Ограничения исследования

- **Слабая разметка** интентов на уровне реплик — внутренние неточности эвристических правил.
- **Дисбаланс классов** в 14-классовой схеме речевых актов.
- **Дубликаты и перекрытие сплитов** в исходном `DialogSum-RU`.
- **Качество машинного перевода** ru-версии датасета.
- **Ограничения вычислительных ресурсов** — fine-tuning ограничен компактными моделями (RuBERT-tiny2).
- **Ограничения классических методов** TF-IDF/LDA/NMF при работе с диалогами.

## Перспективы дальнейших исследований

- Расширение и улучшение ручной разметки интентов.
- Эксперименты с более крупными русскоязычными LM (RuBERT-base/large, ruRoBERTa, LLM-классификаторы).
- Использование тематических кластеров как иерархического признака в multi-task сценарии.
- Применение конвейера к доменно-специфичным русскоязычным диалогам.
